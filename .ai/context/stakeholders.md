# Stakeholders

| Role | Need | Decision right |
| --- | --- | --- |
| Product owner | User value and outcome clarity | Accept outcomes, bets, and product reviews |
| Architecture owner | Coherent boundaries | Accept architecture decisions and exceptions |
| Delivery owner | Executable scope | Accept milestones and tickets |
| Security reviewer | Safe autonomy | Approve R2/R3 work |
| Metrics owner | Honest evidence | Own thresholds and alerts |
| Users | Solved problems | Provide external outcome evidence |
