# Conventions

- Outcomes: `O-NNN`
- Opportunities: `OP-NNN`
- Experiments: `EXP-NNN`
- Bets: `BET-NNN`
- Milestones: `M-NNN`
- PRDs: `PRD-NNN`
- Change requests: `CR-NNN`
- Reviews: `REVIEW-NNN`
- Tickets remain at stable paths and use status metadata rather than folder moves.
- Generated files include a warning header and are replaced atomically.
