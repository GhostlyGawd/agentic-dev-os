# Pitfalls

- Duplicating PRDs under `.ai/planning/` and `docs/prd/`.
- Moving ticket files between status directories and breaking trace paths.
- Treating a hypothesis as evidence.
- Allowing a generated CSV to become the real source.
- Closing a milestone because tests pass without reviewing the user outcome.
- Treating seeded demo content as market evidence; label synthetic examples "synthetic demo hypothesis" the moment they appear and exclude them from validation claims (FINDING-001).
