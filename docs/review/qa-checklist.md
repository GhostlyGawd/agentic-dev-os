# Product QA Checklist

## Product Fit
- Does the result still solve the linked opportunity?
- Is the intended user still the primary beneficiary?
- Did anything dilute the product promise?

## Scope Control
- Does every behavior link to a requirement?
- Did scope changes use an approved change request?
- Can anything be removed without harming the outcome?

## Completion
- Are acceptance criteria and evidence complete?
- Is the milestone shippable now?
- Is post-release observation defined?

## Risk
- What remains ambiguous?
- Which failure requires observation instead of more pre-release scope?
