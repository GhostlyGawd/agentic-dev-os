# Support

Agentic Development Operating System is a Lab-stage portfolio pilot candidate. Support is best effort; no response-time or resolution-time SLA is promised.

## Where to ask

- Use GitHub Discussions for usage questions, design discussion, and adoption feedback containing no sensitive information.
- Use GitHub Issues for reproducible defects in the current source snapshot.
- Follow [CONTRIBUTING.md](CONTRIBUTING.md) for proposed changes and pull requests.
- Follow [SECURITY.md](SECURITY.md) for suspected vulnerabilities. Never disclose exploit details publicly.

Before opening a public issue, include the full commit SHA, Python version, operating system, command, expected result, actual sanitized result, and smallest reproduction. Remove credentials, personal paths, client data, production data, and private research.

## Supported surface

- `main` receives best-effort fixes during the bounded pilot.
- No tag, package, stable version line, hosted service, or production support commitment exists.
- The documented source workflow assumes Python 3.11+, Git, GNU Make, and a Unix-like shell.
- Consumer repositories remain responsible for their own domain behavior, threat model, deployment, data, and support.

If a future release changes this policy, release notes and the security policy must say so explicitly. Until then, an issue or discussion response does not create a compatibility or maintenance commitment.
